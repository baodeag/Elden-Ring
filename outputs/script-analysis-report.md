# Báo Cáo Script Unity - Elden Ring

Ngày tạo: 2026-06-09. Tổng số script đọc: **288**.

## Ghi chú đọc bảng

- **Loại**: MonoBehaviour/NetworkBehaviour/ScriptableObject/Data/Editor suy ra từ kế thừa và vị trí thư mục.
- **Cha**: base class nội bộ dự án. **Con**: script kế thừa trực tiếp từ script đó.
- **Liên quan**: script nội bộ được nhắc tới trong code, gồm field, property, tham số, gọi method hoặc generic.
- **Gắn asset**: số scene/prefab/asset YAML có tham chiếu GUID script này; đây là dấu hiệu script đang được gắn component hoặc dùng làm asset.

## Tổng quan kiến trúc

| Cụm | Vai trò | Script tiêu biểu |
